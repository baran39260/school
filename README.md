# 🎓 بازی‌های آموزشی ریاضی - Math Learning Games

مجموعه‌ای از بازی‌های تعاملی آموزشی برای یادگیری مفاهیم ریاضی به زبان فارسی

## 🎮 بازی‌های موجود

### 1. 📅 ماجراجویی تقویم جادویی
- **فایل:** `days.html`
- **موضوع:** یادگیری شمارش با استفاده از تقویم و هفته‌ها
- **سن مناسب:** 6-10 سال
- **مفاهیم:** شمارش، هفته‌ها، ضرب پایه

### 2. 🎢 ماجراجویی جمعه‌های جادویی
- **فایل:** `friday_math.html`
- **موضوع:** داستان پارک تفریحی و یادگیری ریاضی
- **سن مناسب:** 7-12 سال
- **مفاهیم:** جمع، تفریق، حل مسئله

### 3. ✖️ آموزش ضرب با گروه‌بندی
- **فایل:** `multiplication_intro.html`
- **موضوع:** یادگیری مفهوم ضرب از طریق گروه‌بندی
- **سن مناسب:** 8-12 سال
- **مفاهیم:** ضرب، گروه‌بندی، شمارش

### 4. 🔢 مقدمه‌ای بر ضرب
- **فایل:** `multiplication_intro2.html`
- **موضوع:** تمرینات اضافی ضرب
- **سن مناسب:** 8-12 سال
- **مفاهیم:** ضرب، تمرین، تقویت

### 5. 🎯 ریاضی شنبه‌ها
- **فایل:** `saturday_math.html`
- **موضوع:** تمرینات ریاضی برای شنبه‌ها
- **سن مناسب:** 6-10 سال
- **مفاهیم:** جمع، تفریق، شمارش

## 🚀 نحوه استفاده

### روش 1: دانلود مستقیم
1. فایل HTML مورد نظر را دانلود کنید
2. روی فایل دابل کلیک کنید
3. در مرورگر باز می‌شود

### روش 2: استفاده آنلاین
1. روی لینک فایل کلیک کنید
2. مستقیماً در مرورگر باز می‌شود
3. نیازی به دانلود نیست
